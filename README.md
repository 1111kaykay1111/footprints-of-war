# Footprints of War

Grade 9 History virtual field trip: World War II (1919–1945). JMH 454 group assignment, University of Pretoria.

16 stops in date order on a 3D globe, each with a live Google satellite map, Street View, historical evidence, films, learner tasks and a quick check. Ends with a chronology challenge.

Globe built with [globe.gl](https://github.com/vasturiano/globe.gl) (MIT). Globe imagery: NASA Blue Marble.
